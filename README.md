# Mono Booth

Mono Booth is a web-based photo booth application that lets users capture photos using their device camera and access a dedicated studio for photo customization and downloads.

## Features

- **Camera Capture**: Take photos directly from the browser.
- **Countdown Timer**: Prepare before capturing a photo.
- **Flash Effect**: Toggle the on-screen flash effect.
- **Photo Studio**: Customize and work with captured photos.
- **Photo Download**: Access the download page for saved photo results.
- **Responsive Interface**: Web-based interface designed for easy navigation.

## Tech Stack

- **HTML5**: Web page structure and camera interface.
- **CSS3**: Styling and responsive layouts.
- **JavaScript**: Camera interactions and photo processing.
- **Web Media APIs**: Access the device camera through the browser.
- **Google Fonts**: Typography using Poppins.

## Getting Started

### Prerequisites

- A modern web browser
- A device with a camera for photo capture
- A local web server for development

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/najlanafisah/mono-booth.git
   cd mono-booth
   ```

2. Run the project using a local development server, such as the Live Server extension in Visual Studio Code.

3. Open the local URL provided by the server in your browser.

4. Allow camera access when prompted.
